# Contributing

Vorra follows the implementation roadmap in `docs/12-development-roadmap.md`.

## Standards

- Keep changes scoped to one feature or phase.
- Use TypeScript strict mode.
- Keep user funds non-custodial.
- Include the hackathon attribution tag in every eligible Celo transaction.
- Update docs when implementation behavior changes.

## Commits

Use conventional commits:

```text
feat: add escrow contract
fix: validate wallet signature
docs: update hackathon submission checklist
```
