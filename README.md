# Vorra

Vorra is an AI-powered B2B procurement marketplace for African businesses. Buyers can discover trusted suppliers, compare products with AI assistance, and complete secure cUSD escrow payments on Celo.

## Hackathon

Vorra is registered for the Celo Agentic Payments & DeFAI Hackathon.

- Track: Most Revenue Generated
- Attribution tag: `celo_5fdfafd97630`
- Public repo: <https://github.com/jedi-dtechmaker/vorra-celo>

Every eligible on-chain transaction must include the assigned attribution tag.

## Workspace

```text
apps/
  web/      React + Vite frontend
  api/      NestJS backend
packages/
  shared/   Shared constants, schemas, and types
  ui/       Shared UI primitives
  contracts/ Solidity contracts and deployment scripts
  config/   Shared tooling config
docs/       Product and architecture documentation
plans/      Hackathon and execution plans
```

## Development

Install dependencies with pnpm, then run the desired workspace script.

```bash
pnpm install
pnpm dev
pnpm dev:api
```
